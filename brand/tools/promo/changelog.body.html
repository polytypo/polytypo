What changed, and what it costs

Every released version, and what it does to text you already have.

Versions here are spec versions, and every runtime publishes the same number: {{latest_version}} on npm, PyPI, pkg.go.dev, RubyGems and Packagist is the same spec and the same bytes out. Only released versions appear — what sits unreleased in the repository is not a changelog entry.

Each entry is a behaviour change with its cost stated: a rule that starts firing where it did not before also fires somewhere you may not want it, and both sides are pinned by fixtures. In the tables below, ⍽ stands for U+00A0 NO-BREAK SPACE and · for U+202F NARROW NO-BREAK SPACE; neither is in the output itself — showing them is the only way a changelog can say what the nbsp rule actually did.
