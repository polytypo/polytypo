How the conversion works

Pick the locale you are writing in and polytypo sets that locale’s own quotation marks, not one universal pair: the same straight quotes come out differently in en-US, en-GB and de-DE. It reads each apostrophe and each quote in context, so It's gets a proper apostrophe and a nested 'quiet' inside double quotes gets the right inner pair. Dashes, ellipses and no-break spaces are set in the same pass.

Curly quotes you paste in are not turned back into straight ones. Text that is already curly is set to the selected locale’s marks, as the last example shows. The text, html, markdown and yaml modes cover plain text, web pages, Markdown and the prose values of YAML files. The quotes rule documents every locale’s pairs, and the runtime pages show how to install polytypo for JavaScript and TypeScript, Python, Go, Ruby and PHP.

What to know before you paste

None of the options fall back to a default

A wrong or missing value throws its own error with a machine-readable code, rather than guessing what you meant.

Idempotent

Paste the output back into the input and nothing should change.

YAML values and colons

In yaml mode, a value written plainly cannot contain :  — YAML itself reads that as a nested mapping, and a document with one does not parse at all. polytypo declines such a line rather than rewrite text it could not read back, so it returns untouched even when its key is named in keys. Quote the value, or write it as a block scalar with |. A quoted value may contain colons freely, but not an escape (\" or ''): that would make the source and the content different strings, and the offsets this mode works in are source offsets.

Size

No hard size limit on transform() — ordinary prose runs at roughly 250K characters per second, so even a full novel pasted in typesets in a couple of seconds. Pathological input (long runs of alternating quote or dash characters with no real content between them) is measurably slower, since a couple of rules re-check their own output to guarantee idempotency — real text never has that shape, so this only matters if you're piping in machine-generated or adversarial input.
