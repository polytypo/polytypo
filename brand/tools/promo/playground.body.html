YAML values and colons

In yaml mode, a value written plainly cannot contain :  — YAML itself reads that as a nested mapping, and a document with one does not parse at all. polytypo declines such a line rather than rewrite text it could not read back, so it returns untouched even when its key is named in keys. Quote the value, or write it as a block scalar with |. A quoted value may contain colons freely, but not an escape (\" or ''): that would make the source and the content different strings, and the offsets this mode works in are source offsets.

Size

No hard size limit on transform() — ordinary prose runs at roughly 250K characters per second, so even a full novel pasted in typesets in a couple of seconds. Pathological input (long runs of alternating quote or dash characters with no real content between them) is measurably slower, since a couple of rules re-check their own output to guarantee idempotency — real text never has that shape, so this only matters if you're piping in machine-generated or adversarial input.
