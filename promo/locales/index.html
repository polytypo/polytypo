Typography rules by locale

Typography rules for 35 locales: quotes, dashes, spaces.

Every locale below is a data file with a normative source cited for each rule it sets, backed by fixtures the conformance suite runs on every change. Each locale has its own page with the quotation marks, dashes, ellipsis, no-break spaces, worked examples and the full list of sources.

The same sentence, 35 locales

Nobody agrees about quotation marks.

German lowers the opening quote. Swiss German turns it into guillemets pointing outward. French puts a no-break space inside them (U+00A0) and a narrow one before ! ? ; (U+202F). Finnish and Swedish close with the same glyph they open with. British English swaps the primary and secondary levels round. Every one of these is correct — in exactly one place.
