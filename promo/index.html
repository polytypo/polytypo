«—» is typography, not an AI watermark.

polytypo fixes typography in any text: it turns straight quotes into the locale's quotation marks, sets dashes and ellipses, and inserts no-break spaces. It supports 27 locales in JavaScript, Python, Go, Ruby and PHP, and gives byte-identical output in all five.

English (US) opens with a curly double quote and a tight em dash. British English swaps the primary and secondary levels round, with a spaced en dash instead. German lowers the opening quote. Swiss German turns it into guillemets pointing outward. French puts a no-break space inside its guillemets (U+00A0) and a narrow one before ! ? ; (U+202F). Russian pairs French-style guillemets with German's low-high secondary marks. Every one of these is correct — in exactly one place.

Questions

Common questions

How do I turn straight quotes into curly quotes automatically?

Call transform(text, { locale }). It replaces straight quotes with the locale's primary and secondary pairs, for example “…” in en-US and „…“ in de-DE, and resolves nesting.

Which languages does polytypo support?

27 locales, each backed by cited style guides. See typography rules by language.

Can it typeset Markdown, MDX, HTML and YAML without breaking code?

Yes. The markdown, html and yaml modes change only prose and leave tags, attributes, code spans, code blocks and URLs alone. See modes.

Does running it twice change the text again?

No. transform(transform(x)) equals transform(x) in every runtime; see idempotency.

Is the em dash a sign of AI-written text?

No. It is standard punctuation in several style guides, and polytypo sets it only where a locale's guide prescribes it. Read the manifesto.
